# Industry4.0
This is a repository to archive the buildup of a fictional Industry from the Industry 3.0 to 4.0.

The lack of visibility of the factory performance (OEE) makes the bussiness decision making difficult or ineficient.

So I implemented an achiteture based on UNS to centralize the data and make the decision making more easy and in real time.

## Beginning
This plant has the PLCs and HMIs connected through an internal network and isolated from the IT network.

Some of the data gathered is sent to OPC-UA server and then avaliable to the IT side of bussiness to be analyzed.

This configuration makes this plant on the first half of the 2° step (there isn't a MES) of the ACATECH development path.

This scenario only allowed the production planning generated by the ERP to be printed and physically distributed to the operators.

Also management didn't have visibility in real-time of the OEE, relying on spreadsheets filled on end of shift.

All the vital information gathered is stored in SQL databases to them be transformed into reports, most of them not updated for a day.

## The first mission
To begin the digital transformation of this plant we are going to structure it until the 3° step, **Visibility**.

For that it was implemented an architecture based on UNS (Unified Name Space) using the MQTT protocol as base.
